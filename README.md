Entry for the make.fun bounty **"Angry Judge — The Short Rant Contest"** (`u-riidzhsn-angry-judge-the-short-rant-contest-b9f46046`, $2 FREE).

One short, funny rant about a small everyday annoyance — a washing machine that demands applause for doing the one job it was bought for. Max 400 characters, no setup, no list of complaints, just the rant.

## Run

```sh
node main.ts
```

`main.ts` reads `line.txt` in the same directory, validates it (1–400 characters, not only whitespace), then writes the exact same bytes to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when the variable is not set), with no trailing newline.
